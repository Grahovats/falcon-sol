# Brand — Falcon

Falcon is a competitive trading platform that treats trading as a skill sport, never as casino entertainment.

- Direction: dark, tactical, precise, and professional.
- Voice: concise command language; use missions, deploy, operators, and command board where natural.
- Palette: near-black cool surfaces, restrained borders, soft white text, and one acid-lime operational accent.
- Typography: use the home page’s shared sans-serif font throughout the UI, including labels, numeric data, and charts. Keep tabular numerals where values need to align.
- Motion: minimal and functional; respect reduced-motion preferences.
